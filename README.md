# SAO Armory downloads

Windows app releases and sanitized shared game knowledge for SAO Armory.

The download page is https://supernova-sao-guide.netlify.app. Minecraft account verification and owner approval are required to use the app.

The scheduled publisher checks daily and combines new discoveries into a cumulative snapshot every three days. It verifies every published part through the guild service before clearing archived discoveries from the temporary queue. Membership, ranks, requests, and map alignment remain in the service. No personal builds, notes, chat, inventory quantities, credentials, or location history are published.

Large files use GitHub Releases. The workflow uses standard public-repository GitHub Actions runners, without paid runners, caches, or Actions artifact storage. Keep the Netlify site and Cloudflare service on their Free plans. Service quotas can interrupt availability; no paid upgrades or recharges are configured by this repository.

Do not delete data releases referenced by a snapshot manifest. Each snapshot is cumulative and may reuse unchanged parts from earlier releases.
